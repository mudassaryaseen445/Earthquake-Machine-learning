# Earthquake-Machine-learning
Machine Learning project using earthquake data for classification and regression tasks including tsunami and earthquake magnitude prediction
## Earthquake Machine Learning
This project applies Machine Learning techniques to an earthquake dataset for both classification and regression tasks.
# Project Overview
The project explores earthquake data and builds machine learning models for two different prediction problems:
- # Classification: Predict whether an earthquake is associated with a tsunami.
- # Regression: Predict the earthquake's magnitude.
## Machine Learning Tasks
# 1.Classification
The classification task uses Tsunami as the target variable.
Models explored:
- Random Forest Classifier
- Gaussian Naive Bayes
- Logistic Regression
- Decision Tree Classifier
Model predictions were evaluated using accuracy and other classification evaluation techniques.
# 2.Regression
The regression task uses Magnitude as the target variable.
Models explored:
- Linear Regression
- Support Vector Regression (SVR)
- Decision Tree Regression
- Random Forest Regression
Regression models were evaluated using:
- R² Score
- Mean Absolute Error (MAE)
## Workflow
The project follows a typical Machine Learning workflow:
- Data loading
- Data exploration
- Data preprocessing
- Feature and target selection
- Train-test split
- Model training
- Prediction
- Model evaluation
- Visualization of actual vs predicted values
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
## Purpose
The purpose of this project is to practice and demonstrate the application of different Machine Learning algorithms to the same real-world earthquake dataset using both classification and regression approaches.
